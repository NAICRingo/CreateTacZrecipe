# Changelog

## 0.2.0-rc1

- Package the owned KubeJS startup/server scripts and resources inside the mod JAR.
- Add the KubeJS plugin entry point that loads the bundled scripts as read-only packs.
- Preserve the 22 default ammunition definitions and six conservative gun-pack adapters.
- Add project-owned models and original 16x16 textures, including distinguishable
  measured propellant charges for all default calibers.
- Keep Create Diesel Generators molding, primer production, projectile polishing and
  Create sequenced assembly behavior from the validated development version.
- Remove Create Deco from runtime requirements and default material economics.
- Add release-content checks for scripts, models, textures, translations, catalog
  coverage, deferred ammunition and excluded third-party reference material.
